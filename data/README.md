# Data

The original competition dataset contains high-frequency smart-factory electrical measurements and the target power-consumption series.

Raw competition data are not included in this repository.

The original team analysis used:
- module/equipment identifiers
- active and reactive power measurements
- accumulated active energy
- phase-level voltage/current measurements
- power factor measurements
- datetime information

The raw 5-second measurements were aggregated to 10-minute intervals before modeling.
